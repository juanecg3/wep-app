Objetivo 1: El Box Model

Ambas cajas tienen width: 300px, padding: 20px y border: 5px solid.

❌ content-box (default)

300px

width (300) + padding (20×2) + border (5×2)

= 350px de ancho real 😱

✅ border-box

300px

width (300) incluye padding y border

= 300px de ancho real ✅

Regla #1: Siempre pon *, *::before, *::after { box-sizing: border-box; } al inicio de tu CSS.
